# プライバシーポリシー

「Challenge the Numbers」（以下「本アプリ」）は、以下の方針に基づき、ユーザーのプライバシーを尊重します。

## 収集する情報

本アプリは、広告配信のために Google AdMob を使用しています。AdMob は広告の表示や効果測定のために、端末の広告識別子（IDFA）などの情報を収集する場合があります。

本アプリ自体は、ユーザーの氏名、メールアドレスなどの個人情報を収集しません。ゲームの進行状況はお使いの端末内にのみ保存され、外部に送信されることはありません。

## 第三者への情報提供

広告配信に関連して、Google AdMob によって収集された情報は、Google のプライバシーポリシーに基づいて取り扱われます。
詳細: https://policies.google.com/privacy
